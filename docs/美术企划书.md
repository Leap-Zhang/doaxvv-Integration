## 1. 美术定位

### 1.1 一句话
一部**维纳斯群岛「海岛度假」上的泳装攻略百科**——清新、通透、有度假氛围，同时保留图鉴/数据的可读与专业感。

### 1.2 风格关键词
`海岛度假` · `清新` · `通透/玻璃` · `渐变光` · `珊瑚礁配色` · `柔和` · `轻量` · `响应式` · `明暗双主题`

### 1.3 气质
- **正面**：像站在泳池边看一本杂志 —— 阳光、海风、轻盈。
- **克制**：图形语言收敛，用「色 + 玻璃 + 微渐变」叙事，不做厚重插画风。
- **信息优先**：所有装饰不干扰数值与攻略的读取。

## 3. 配色体系

### 3.1 品牌主色
| Token | 色值 | 用途 |
|---|---|---|
| `pool-50` | `#eef7ff` | 最浅底、徽章底 |
| `pool-100` | `#d8edff` | 浅渐变 |
| `pool-300` | `#7fc3f7` | 描边/次级 |
| `pool-500` | `#2b8ae0` | 主按钮、主链接 |
| `pool-700` | `#1c5a99` | 标题/强调文字 |
| `pool-900` | `#123a63` | hero 遮罩深色端 |
| `sand-500` | `#dfb24a` | 辅助金 |
| `blush-500` | `#e56a92` | 辅助粉 |
| `ink` | `#16324a` | 主文字 |
| `ink-soft` | `#5a7288` | 次级文字 |
| `mist` | `#f5f9fd` | 页面底色 |
| `line` | `#e2ecf5` | 分割线/边框 |

### 3.2 属性语义色（重点）
用于「女孩/泳装/技能」数值与标签，是全站统一语言。
| 属性 | 色值 | 类 |
|---|---|---|
| POW 力量 | `#e5566d`（红/玫红） | `attr-pow` / `chip-pow` / `type-pow` / `bg-type-pow` |
| TEC 技巧 | `#2f9e6b`（绿） | `attr-tec` / `chip-tec` / `type-tec` / `bg-type-tec` |
| STM 体力 | `#e0a53c`（琥珀金） | `attr-stm` / `chip-stm` / `type-stm` / `bg-type-stm` |
| APL 魅力 | `#a86fd0`（紫） | `attr-apl` / `chip-apl` |

- `attr-*`：数值/文字色。
- `chip-*`：属性徽章底（半透明同色底 + 深字）。
- `type-*`：女孩类型（力量/技巧/体力）文字色。
- `bg-type-*`：角色卡/详情立绘区的类型渐变背景。

### 3.3 深色模式（.dark）
- 底色改为深青蓝渐变 `#0b1524 → #0f172a → #1a1020`。
- 卡底 `rgba(22,35,58,.92)`；玻璃卡 `rgba(30,41,59,.6)`。
- 属性色提亮：pow `#ff90a2`、tec `#63d1a0`、stm `#f4c26c`、apl `#caa2f0`。

## 4. 背景系统

| 层级 | 实现 | 说明 |
|---|---|---|
| 页面底色 | `linear-gradient(180deg, pool-50, mist, #fbf3f8)` `fixed` | 垂直三段：天蓝→雾白→腮红粉 |
| 环境光晕 | `body::before` 三层 `radial-gradient` | 右上「太阳」蓝、左下「海水」粉、上方「晚霞」金（低透明度） |
| 深色底 | 深青蓝渐变 + 更暗光晕 | 夜间 |

> 原则：背景只提供「氛围」，不抢内容。

## 6. 图形与装饰语言

- **顶部渐变细线**：卡片深意，蓝→粉→金，hover 淡入。
- **类型渐变背景**：女孩卡/详情立绘区按 力量/技巧/体力 用红/绿/金渐变底。
- **Emoji 底纹块**：首页卡片图标放在 `pool-50→blush-200` 渐变方块内。
- **玻璃导航**：`bg-white/85` + 模糊；当前项为蓝渐变胶囊 + 阴影。
- **Logo**：`pool-400→500→700` 渐变 + 白描边光圈。

## 7. 动效与交互

| 交互 | 动效 | 时长 |
|---|---|---|
| 卡片 hover | 上浮 + 阴影加深 + 渐变细线淡入 | 300ms |
| 按钮 hover | 上浮 + 投影放大 | 300ms |
| 导航项 | 背景/渐变过渡 | 200ms |
| 页面滚动 | `scroll-behavior:smooth` | — |
| 高亮滑入 | `.card-wiki::before` opacity | 300ms |

> 遵循「尊重减弱动效」：尽量不使用大幅位移动画，仅用过渡/位移 1–4px。

## 9. 可访问性与响应式

- **对比度**：`ink` on `mist` 为主文本；属性色在浅/深色下均提供提亮变体，避免过浅。
- **焦点可见**：`:focus-visible` 蓝描边。
- **选中**：`::selection` 泳池蓝。
- **响应式**：容器 `max-w-6xl`；栅格 1/2/4 列自适应；导航折叠为移动菜单。
- **深色模式**：全组件（卡/表/徽章/输入/导航/属性色/背景）已适配。

## 10. 扩展方向（后续可选）

1. **泳装卡类型光晕描边**：给泳装卡加一层按属性色的柔光描边，强化类型识别。
2. **Per-type 立绘氛围色**：女孩页头部加类型色环境光。
3. **轻量插画/纹理**：泳池波光、沙滩纹理（低透明度 SVG/CSS），增强度假感。
4. **Lottie/微动效**：hero 微动效（海浪、气泡），需控制体积与动效预算。
5. **品牌化细节**：统一 favicon / OG / 社交横幅（可用 hero 图）。

---

## 11. 验收标准

- 打开任一页面：背景氛围自然、卡片通透、无刺眼纯色大块。
- 数值/标签属性色全站一致（POW 红 / TEC 绿 / STM 金 / APL 紫），明暗两套均可用。
- 全站组件复用统一类（card-wiki / badge / chip / attr-*），不出现散落的自定义样式。
- 移动端与桌面端均可正常浏览；焦点环、选中态、滚动条美观可用。
- 图片全本地化、WebP、体积受控（避免首屏大图阻塞）。

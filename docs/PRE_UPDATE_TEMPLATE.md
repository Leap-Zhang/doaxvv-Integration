## 三、发布前核对清单（逐项打勾）
### 构建与产物
- [ ] `pnpm build` 通过（页面数 = ___ ）
- [ ] `dist/` 生成了本次涉及的页面
- [ ] 无控制台/编译报错

### 关键页面可达（本地 `pnpm preview` 后逐页 200）
- [ ] `/` `/girls` `/swimsuits` `/skills` `/guide` `/community`
- [ ] `/reference` `/tools` `/collection` `/search` `/updates` `/sections`
- [ ] 各详情/弹窗（女孩详情、泳装弹窗、技能弹窗）

### 数据与链接
- [ ] `public/data/*.json` 已同步 + 在 `dist/data/` 存在
- [ ] 官方公告 `official-news.json` 就绪（非空）
- [ ] 站内跳转无 404（角色↔泳装↔技能↔资料库）
- [ ] 外链（原帖/官网/doax.cc）有效

### 视觉 / 无障碍
- [ ] 明暗两种主题都正常
- [ ] 三语（中/英/日）正常；日文走 `Yu Gothic UI / Meiryo…`
- [ ] 卡片圆角/阴影/毛玻璃统一
- [ ] 对比度：小字 13px、正文 pool-700、弱对比可见
- [ ] 移动端（汉堡抽屉/横向滚动菜单）可用
- [ ] 图片有 `alt`；焦点可见

### 风险 / 回退
- [ ] 关键改动点在 `/sections` 有编号，便于“改 #N”
- [ ] 若有高险：可 `git revert` 回退

## 四、上线与验收
- [ ] `git add -A && git commit -m "..."`（未要求推送则不动）
- [ ] 如需推送：`git push`（代理重试）→ Actions 构建 → 部署
- [ ] 线上验证：`<用户名>.github.io/<仓>/…` 关键页 200
- [ ] 数据自动更新 workflow 就绪（`update-data.yml`，每天 02:00）

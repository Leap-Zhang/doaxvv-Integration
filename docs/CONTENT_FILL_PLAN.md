## 三、分阶段路线
### P0 · 官方源 + 结论化（先做）
1. **官网深度**：把官网 **Spec** 做成站内「关于·运行配置」页；抓 **Game Help 各主题正文**（中文化，补全 `/help`）；抓 **维护公告**并入“官方动态”。
2. **女孩结论化**：每个女孩算**理论最高（基础+满级+满强化+PP+涂油+应援板）**，给**配装推荐**与**特性标签**（如“刷分/爬山/竞技场”）。
3. **泳装推荐**：按**属性倾向**给出“泳装怎么选”，标**当期/复刻**；技能效果**多语补齐**。

### P1 · 深度与扩容
4. **系统指南**：细化属性机制/公式、流行数值、爬塔/竞技场进阶；加入官网帮助对应段落。
5. **社区扩容**：持续收集贴吧/B站攻略，做**版本/活动专题**，并把“适用度高”的编排成站内精读。
6. **饰品/声援板**：补数值加成与推荐，接进面板估算。

### P2 · 工具与体验
7. **面板估算升级**：接入饰品/潜力数值加成；**属性对比**扩展到泳装/配装。
8. **收藏导出/导入**、**留言分类/Markdown**（纯本地）。
9. **性能/无障碍**：lazy 加载审计、焦点/减少动效、`text-xs` 统一等（你已做过一部分，保持）。

## 四、数据管道（扩展“自动更新”）
- `data:update` 扩为：doax.cc 数据 + **官网公告(分类+正文)** + **维护公告** + **角色官方档案** + **帮助/规格**（按源分脚本）。
- GitHub Actions 每日 02:00 自动拉取并本地化；有变更→提交推送→自动部署。

- 每次更新用 `docs/PRE_UPDATE_TEMPLATE.md` 核对：构建通过、关键页 200、数据齐、链接有效、明暗/三语/无障碍。
